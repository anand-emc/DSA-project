# Data Structure Visualizer — Mini Project

## Files
- index.html — website structure
- style.css — responsive design and theme
- script.js — interactive data structures and algorithms

## How to run
Open `index.html` in Chrome, Edge, Firefox, or another modern browser.
No server or external library is required.

## Included
- Stack: Push, Pop, Clear
- Queue: Enqueue, Dequeue, Clear
- Singly Linked List: Insert, Delete Head, Clear
- Binary Search Tree: Insert, Search, Clear
- Algorithms: Bubble Sort, Selection Sort, Insertion Sort, Linear Search, Binary Search
- Light/Dark theme
- Responsive layout
